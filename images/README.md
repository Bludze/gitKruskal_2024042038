# 截图目录

README 与报告中的图片放在本目录。上传仓库后，请按下表命名替换占位图。

| 文件名 | 内容 | 用于 |
| --- | --- | --- |
| `gui-main.png` | 图形界面主窗口（含图设置、边输入、画布） | README |
| `gui-animation.png` | 算法运行中，正在高亮考察某条边 | README |
| `gui-result.png` | 动画结束，红色显示最小生成树与总权重 | README |
| `repo-home.png` | GitHub 仓库首页（About、README 渲染效果） | 报告 图 2-2 |
| `license.png` | LICENSE 文件页面 | 报告 图 2-1 |
| `branches.png` | 分支列表页 | 报告 图 3-1 |
| `conflict.png` | 冲突解决界面或解决前后的提交记录 | 报告 图 3-2 |
| `issue-list.png` | Issue 列表（含 label） | 报告 图 4-1 |
| `issue-detail.png` | 一条 Issue 的完整讨论与关闭状态 | 报告 图 4-1（可选） |
| `stars.png` | Watch / Star / Fork 计数区域 | 报告 图 4-2 |
| `pr-list.png` | Pull Request 列表 | 报告未用（可选） |
| `pr-review.png` | PR 的 Files changed / Review 讨论 | 报告未用（可选） |
| `actions.png` | GitHub Actions CI 运行成功页面 | 报告未用（可选） |
| `release.png` | Releases 页面（v1.0.0） | 报告未用（可选） |

截图建议：浏览器 100% 缩放，只截相关内容区域，避免包含个人信息；深色/浅色主题保持一致。
